TAHUNUTRIFEED - VERSI STATIS UNTUK GITHUB PAGES

Isi: index.html, produk.html, tentang.html, dampak.html, assets/style.css, assets/logo.svg

Cara publikasi:
1. Ekstrak ZIP.
2. Buat repository baru di GitHub.
3. Unggah semua isi folder ke root repository.
4. Buka Settings > Pages.
5. Pada Build and deployment pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu proses selesai, lalu buka URL GitHub Pages yang diberikan.

Catatan: ini versi tampilan statis tanpa PHP/MySQL. Produk dan harga contoh ditulis langsung di HTML. Periksa harga, produk, dan nomor WhatsApp sebelum dipublikasikan.
